# 5-Minute Meditation Timer

A simple, elegant 5-minute meditation timer web app. Settle in, press start, and let the timer guide your short mindfulness session with a calming interface and an audio cue when time is up.

## Features

- **5-minute countdown timer** — clean, large display
- **Start / pause / reset controls**
- **Audio chime** when the session completes
- **Calming design** — distraction-free, single-screen UI
- **Zero dependencies** — one self-contained HTML file, no build step

## Quick Start

No install needed. Just open `index.html` in any modern browser:

```bash
open index.html
# or
python3 -m http.server 8000
# then visit http://localhost:8000
```
